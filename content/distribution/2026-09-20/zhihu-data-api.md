如果是“登录成功，后台列表返回 502”，先看具体失败接口和上游日志。Aperture 在 2026 年 9 月 14 日遇到的原因是 Aurora Data API 返回体积超限。

当时只查最近 20 条研究记录，但完整查询 JSON 已有 1,094,895 字节，超过 1 MiB。审核信息不断累积，固定条数并不能限制每行的大小。AWS 文档还分别限制单行大小，因此简单改成 LIMIT 1 也不能保证超大 JSON 字段可读。

我们的处理方法是：

1. 把查询行序列化，再按 8,192 字符切块，每次最多取 8 块。
2. 游标同时记录“第几行、第几块”，完整拼接后再解析 JSON。
3. 多次读取放在同一只读、可重复读快照中，防止并发写入改变记录顺序或版本。
4. 验证最新 20 条、单条超大记录、中文和 emoji、空列表及并发读取，最后再测线上接口。

当次部署后十个后台初始化接口均返回 200。这个方案有额外查询开销，适合必须保留完整字段的需求；如果列表只需要摘要，按需加载详情也值得考虑。
